# Überlegungen: thoughts on memory

*Überlegungen* is German for reflections. German has two words for memory: *Gedächtnis*, the faculty, and *Erinnerung*, a single thing remembered. A second brain needs both.

## Für später

- How much structure does a memory need before it gets heavy?
- What belongs in a diary, and what in a vault? (*Tagebuch* or *Tresor*: both are private, only one is locked.)
