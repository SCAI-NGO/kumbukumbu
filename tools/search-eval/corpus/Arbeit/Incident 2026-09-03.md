# Incident 2026-09-03: database outage

Duration 47 minutes, all write requests failed.

## Timeline

- 09:12 alerts for failed writes
- 09:20 on-call identifies the primary as read-only
- 09:59 disk cleaned, primary writable again

## Root cause

The primary's data disk ran full: WAL archiving to object storage had silently failed for two days, so old WAL segments piled up.

## Action items

- Alert when a disk passes 80 %
- Alert when WAL archiving fails
- Runbook for a full primary disk
