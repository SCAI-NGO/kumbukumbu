## Ground rules

- **Start from `master`** at or after `ed08aa0` (OAuth, PR #28, is merged). Every PR has its own branch off `master` and its own plan; one plan, one branch, one PR.
- **Chris merges every PR himself.** Agents never merge into `master`, never push to `master`, never tag. Open the PR when the plan's last task is done: tests green, the plan's review done, and the PR description listing what Chris should look at.
- **After a PR is merged**, branches that are still open rebase onto the new `master` before they continue (the order below keeps conflicts small).
- Commit messages: imperative, free-form, each ending with the session's attribution lines.
- British English in code, comments, docs and copy; no names, addresses or policies anywhere in the product.
- **Cut-off 20:00 (Europe/Vienna).** Whatever is not open as a PR by then is not started anew: finish the task in progress, push the branch, and write in the PR (draft) or in `docs/notes-v0.2.0-handover.md` exactly where it stopped. Chris hands the rest to an overnight session.
- **If time runs short, drop in this order:** (1) search in earlier versions (activity plan, Task 5), (2) the deleted-ids list with "repeat the deletion" (GDPR plan, Tasks 5–6), (3) the Activity view (activity PR as a whole). **Never dropped:** Obsidian sync (server and plugin), updates and PWA, welcome vault, export.
